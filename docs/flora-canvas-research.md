# FLORA canvas capabilities

Checked September 19, 2026 against the [official documentation index](https://docs.flora.ai/llms.txt) and the linked pages below. These are documented product capabilities, not results from hands-on testing. This note covers FLORA's canvas; the Kousa implementation comparison is a separate code audit.

| Capability | What the current documentation supports |
| --- | --- |
| Conversational canvas agent | FAUNA reads selected nodes and node mentions, creates and connects workflows, changes prompts/models/settings, restructures connections, makes variants, groups and arranges nodes, and runs generations. Assist mode previews execution and estimated usage for approval; Auto mode runs without that pause. It can operate Layer Editor tools. It is limited to the open project; cross-project work and access to past assets/history are explicitly listed as unavailable. [FAUNA](https://docs.flora.ai/editor/fauna) |
| Image reference inputs and visual analysis | Image-to-image workflows transform existing visuals. Connecting an image or video to a Text node lets a model analyze its content. Multiple image references can connect to video nodes, including first/last frame roles where the model supports them. These are input capabilities, beyond simply uploading or displaying media. [Image-to-image](https://docs.flora.ai/nodes/image-node/image-to-image), [image-to-text](https://docs.flora.ai/nodes/text-node/image-to-text), [video-to-text](https://docs.flora.ai/nodes/text-node/video-to-text), [canvas connections](https://docs.flora.ai/editor/canvas) |
| Image editing and composition | Inpainting uses a painted mask; outpainting expands image boundaries with handles. Each edit creates a new node preserving the original. Layer Editor combines connected images into one output with independent positioning, resizing, rotation, flipping, opacity, visibility, locking, layer order, alignment and snapping. A toolbar action splits an image into 2–5 layers. [Image editing](https://docs.flora.ai/editor/image-editing), [Layer Editor](https://docs.flora.ai/nodes/layer-editor), [toolbar](https://docs.flora.ai/editor/toolbar) |
| Batch iteration | A Batch node collects homogeneous image, video or text inputs and runs a connected generation or Technique for each item. Inputs can come from connections, uploads, the asset library, CSV rows, or text split by line/custom delimiter. The documented execution limit is 100 items. This is a collection iterator, distinct from manually drawing several workflow branches. [Batch Node](https://docs.flora.ai/nodes/batch-node) |
| Bulk editing and canvas organization | The canvas supports color tags, bulk parameter/model changes across compatible selected nodes, and reordering connected inputs. FAUNA explicitly supports grouping nodes into containers and arranging them. A Router gathers shared inputs and passes them to multiple downstream nodes; it does not generate content. [Canvas](https://docs.flora.ai/editor/canvas), [FAUNA](https://docs.flora.ai/editor/fauna), [Router](https://docs.flora.ai/nodes/router-node) |
| Video finishing | Timeline is a canvas node with up to 10 tracks for video, audio, text, captions, images and shapes. It supports sequencing, trim/split, placement, crop, opacity, volume, playback speed and fades. It renders MP4 back to the canvas and exports EDL/XML/FCPXML bundles with source media. Connected source nodes feed the timeline. The docs explicitly say this version has no keyframe animation. [Timeline Editor](https://docs.flora.ai/editor/timeline-editor) |
| Reusable subject references | Elements combine subject images, a category and optional guidelines into a named generated reference. Users can reference Elements in prompts or connect Element nodes to compatible image/video generators. The library has private and workspace-shared references, reference history and a chosen default. The documentation does not guarantee perfect subject consistency. [Elements](https://docs.flora.ai/editor/elements) |
| Reusable workflow components and apps | Technique Builder packages a multi-node graph into one reusable node with defined inputs/outputs. Techniques can be private, workspace shared or community listed after review. A simplified app link lets others run the packaged workflow without working on the canvas. Techniques support internal batch processing and editable output parameters when configured. [Technique Builder](https://docs.flora.ai/nodes/technique-builder) |
| Comments and sharing | Collaborators can edit simultaneously, leave comments at canvas positions, share project links, and publish projects to the community. This is separate from Technique sharing. [Collaboration and sharing](https://docs.flora.ai/editor/collaboration-and-sharing), [comment tool](https://docs.flora.ai/editor/toolbar) |
| Non-generative workflow utilities | Action nodes provide crop/pad, rotation, color adjustments, image filtering, text splitting/replacement/concatenation, video stitching, scene splitting, frame extraction, playback changes, watermarking, and audio extraction/merging. Custom Actions turn a written request into a reusable canvas operation with input slots and controls. [Action catalog](https://docs.flora.ai/nodes/action-node), [Custom Actions](https://docs.flora.ai/nodes/custom-actions) |
| Document inputs and delivery | PDF nodes offer page browsing, full-document input to text models, current-page image input, and per-page batch processing. Export nodes provide batch output delivery, format choices and Google Drive integration; Drive integration requires workspace availability. [Document Node](https://docs.flora.ai/nodes/document-node), [Export Node](https://docs.flora.ai/nodes/export-node) |

Scope and uncertainty:

- FLORA's separate spreadsheet-style Batch Generate product and Fashion Studio are not included in this canvas comparison. The Batch Node page explicitly distinguishes the canvas iterator from Batch Generate.
- No dedicated slide/presentation mode was verified. Navigation documents hiding prompt overlays for a cleaner canvas view; Layer Editor lists presentation compositions as a use case. Neither establishes a presentation mode. [Navigation](https://docs.flora.ai/editor/navigation), [Layer Editor](https://docs.flora.ai/nodes/layer-editor)
- The documentation index lists 3D nodes, but the node page was inaccessible during this check. Treat detailed 3D controls as unverified here.
- Model-specific input combinations vary. Do not imply that every image/video model accepts every kind or number of references.

For the Kousa comparison, preserve distinctions between an existing feature and its missing extension: project media versus reusable subject references; whole-canvas templates versus callable Technique components/apps; graph branching versus collection iteration; live collaboration versus comment threads; narrated clip export versus an editable multi-track timeline.
